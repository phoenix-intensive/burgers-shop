## Burger House

Проект Burger House - приложение разработано для демонстрации простой, но функциональной системы заказа бургеров, 
позволяющей пользователям просматривать меню, выбирать любимые бургеры и легко размещать заказы.

## Функции
* Интерактивное меню : пользователи могут просматривать разнообразные бургеры с описаниями, ценами и изображениями.
* Плавная прокрутка навигации : панель навигации позволяет пользователям быстро переходить к различным разделам страницы.
* Форма заказа : пользователи могут заполнить простую форму для размещения заказа, указав свое имя и номер телефона.
* Проверка ввода в режиме реального времени : форма обеспечивает мгновенную обратную связь по введенным пользователем данным, выделяя ошибки для лучшего взаимодействия с пользователем.
* Подтверждение заказа : после успешного размещения заказа пользователи получают всплывающее окно с подтверждением.
  
## Используемые технологии
* Angular : приложение создано с использованием Angular, используя его мощные возможности для реактивных форм и HTTP-запросов.
* Angular Material : используется для реализации компонентов пользовательского интерфейса, таких как диалоговые окна.
* Ngx Mask : библиотека для маскировки ввода, гарантирующая, что пользователи вводят номера телефонов в правильном формате.
* HTML и CSS : для структурирования и стилизации приложения, обеспечения адаптивного и привлекательного дизайна.
